Jogo 2D de exploração sonora para pessoas cegas.

Menu principal

Explore o mapa 2D, encontre a saída e evite a criatura. A voz é obrigatória e os elementos são narrados ao usar Tab.

Como jogar

O mapa é visto de cima. Para quem enxerga, o personagem aparece no mapa. Para quem não enxerga, a narração e os sons descrevem o mundo.

  • W ou seta para cima: andar para cima
  • S ou seta para baixo: andar para baixo
  • A ou seta para esquerda: andar para esquerda
  • D ou seta para direita: andar para direita
  • E: emitir eco e descobrir o ambiente
  • F: interagir com a saída
  • H: ouvir ajuda
  • Esc: voltar ao menu
  • Tab: ouvir o próximo elemento
  • Shift + Tab: ouvir o elemento anterior

Acessibilidade

Narração obrigatória, alto contraste, teclado, foco visível, textos alternativos, sons direcionais e descrição do estado do jogo.
